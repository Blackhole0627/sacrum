# SACRUM

Website and e-commerce for SACRUM: handcrafted religious and decorative sculptures, made by Ecuadorian artisans. Bilingual (ES/EN), with an in-stock catalog and made-to-order customization.

## Contents
- `STEP1-design-and-architecture.md` — scope, sitemap, and data model
- `copy-and-content.md` — the brand's real copy, catalog taxonomy, and asset inventory
- `draft-copy-pending-sections.md` — placeholder copy for the sections the client hasn't written yet (Nosotros, Proceso, Servicios, Contacto), clearly marked as draft
- `wireframes/index.html` — low-fidelity wireframes (open in a browser)
- `tokens.css` — design tokens (black, white product photography, gold accent)
- `shared/store-schema.sql` — the e-commerce data model (shared with the MUBB store)

Step 1 (design and architecture) is complete. Step 2 is implementation.
